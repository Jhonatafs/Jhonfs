about.md

Sobre

Este projeto foi criado para estudar, praticar e demonstrar a lógica da busca binária, um algoritmo usado para encontrar valores em uma coleção ordenada por meio da redução sucessiva do espaço de busca.

A ideia do jogo é simples: o sistema escolhe um número secreto dentro de um intervalo conhecido, e o jogador tenta descobri-lo. A cada tentativa, o jogo informa se o número secreto é maior ou menor que o palpite. Com isso, é possível aplicar a estratégia da busca binária: escolher sempre o meio do intervalo restante e descartar metade das possibilidades a cada passo.

Este projeto está sendo desenvolvido a partir dos estudos acompanhando as aulas do professor Blau Araujo, no canal Debxp: https://www.youtube.com/@debxp.

As aulas fazem parte da série “Lendo e Praticando”, baseada na leitura e prática do livro Entendendo Algoritmos, de Aditya Y. Bhargava.

Inicialmente, criei uma versão do jogo em Shell Script para praticar a lógica da busca binária diretamente no terminal. Depois de apresentar essa primeira versão ao meu amigo Ian, ele gostou da ideia e quis jogar pelo celular. A partir disso, decidi criar uma versão em JavaScript para o site, tornando o projeto mais acessível para quem quiser brincar.
